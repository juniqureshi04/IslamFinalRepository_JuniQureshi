# Beyond the Headlines

This is a static class-project website based on the proposal in `REL340 Proposal document - Juni Qureshi (1).pdf`.

## Files

- `index.html` contains the exhibit structure.
- `styles.css` contains the visual design and responsive layout.
- `data.js` contains the editable project content.
- `app.js` renders the interactive sections.

## How to use it

1. Open `index.html` in a browser.
2. Edit `data.js` to refine the text, add more regions, or expand the timeline.
3. Update the sources section with final citation formatting required by your instructor.
